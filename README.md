# 架枪训练器（M1）

面向 FPS 的网页版瞄准训练器。已实现 **4 种训练模式 × 6 种场景 × 4 档难度**，含音效、准星自定义、灵敏度档案快捷键与实测校准、历史进步曲线。

## 训练模式

| 模式 | 核心指标 | 说明 |
|---|---|---|
| 定位训练 | 一次定位率 / 反应 / 过冲欠冲 | 第一发爆头 = 一次定位，身体命中需补枪 = 二次定位 |
| 拉枪训练 | 拉枪时间 / 拉枪距离 | 竞技场两端交替出靶，任意部位命中即击杀 |
| 预瞄训练 | 预瞄偏差 / 反应 | 敌人从已知点位出现，衡量准星预先放置质量 |
| 架枪训练 | 反应 / 最小位移 | 架住点位，用最小位移第一时间击杀 |
| 跟枪训练 | 跟枪占比 / 反应 | 目标变速横移，按枪口停留在头部的时间计分 |

## 场景（6 个）

窄门过点 / 拐角 peek / 窗口架枪 / 高低差 / 双点位 / 掩体横移（拉枪模式使用竞技场）

## 难度（4 档）

入门 / 普通 / 进阶 / 职业 / 大师 / 极限 —— 影响目标移动速度、头部尺寸、出现间隔与**敌人开火速度**；高难度加入**变速抖动**与**头部晃动**。训练中 F1-F6 快速切换。

## 敌人出场

- 场景模式：敌人从门洞/窗口**深处走近**（由小变大），再横移穿过，不再是凭空出现
- 预瞄模式：敌人从门框边缘**探入 → 停顿 → 缩回**
- 拉枪模式：目标以缩放入场，不瞬移
- 拐角/预瞄敌人**拉出距离随机**：半身位 / 一个身位 / 一点五个身位 / 一大段
- 约 35% 概率**蹲下**（头部明显降低，预瞄爆头线会打空）
- 停位远近随机（纵深缩放 0.6~1.0）
- **停下后会瞄准并开火**：有开火前摇，没在它开枪前击杀就会被击杀（红屏 + 阵亡统计）

## 第一视角枪模

训练画面右下角有第一视角步枪：随鼠标移动摆动（带阻尼回弹）、枪口始终指向准星、开火有后坐力回馈。

## 弹道与开枪效果（无畏契约式）

- **伤害模型**：身体命中 25 伤害（**4 枪致死**），爆头秒杀；拉枪模式任意命中即击杀
- **全自动步枪**：按住左键持续连发（约 583 RPM），松开停止
- **弹匣 25 发**：打空后需要换弹（`R` 键，2.5 秒），HUD 右下角实时显示弹量
- **前 2 发完全精准**：弹着点与准星完全重合
- **第 3 发起散布递增**：连射越多弹道越散（有上限），以上扬为主，难以预判
- **停火 500ms 恢复精准**：鼓励点射与短连发，无脑扫射必然脱靶
- 准星会随散布**张开**（实时反馈当前弹道状态）
- 开枪特效：枪口火光、抛壳（黄铜弹壳带物理）、弹道曳光、枪身回坐
- 散布参数集中在 `src/config/spray.ts`，可调

## 移动系统

- **鼠标移动转视角**：准星固定屏幕中心，鼠标移动转动视角（场景随视角滑动）
- **A / D**：左右横移，视角随之平移（场景在画面中滑动）
- **Ctrl（长按）**：下蹲，视角下移（敌人相对屏幕上移，预瞄高度随之改变）
- **后坐力抬视角**：连射时视角随弹道上扬，松开后回落
- **移动中射击散布极大**：即使前两发也不精准，必须**急停后开枪**——这是 FPS 最核心的肌肉记忆
- 移动状态实时显示在 HUD（站立 / 移动中·散布极大 / 下蹲中）

## 场景与掩体

- 场景带**三维透视感**：透视地板、门洞走廊纵深、砖墙伪 3D 倒角、木天花板、墙面磨损水渍
- **暖光照明**：右侧主光 + 体积光锥 + 高光溢出 + 暗角，全局对比度/饱和度调色
- 敌人带**纵深移动**：从掩体拉出后朝玩家走来（体型变大、位置下移，画在墙前），不会出现被墙裁掉半截的情况
- 敌人会从**不同掩体随机拉出**（右侧大墙 / 中部木箱 / 左侧矮墙），拉出身位、远近、蹲下、开火全部随机

## 击败反馈

- 受击：**血液飞溅粒子**、**伤害数字**（-25 / 爆头）、敌人受击红染与血迹累积、**头顶血条**
- 击杀：**击杀横幅**（爆头击杀 / 双杀 / 三杀 / 四杀 / 五杀+）、右上角**击杀信息栏**（含用弹数与反应时间）、击杀确认音效（连杀越高音调越高）
- 倒地：敌人倒地动画（旋转倒下 + 淡出）

## 第一视角持枪感

枪模带**移动摆动**（横移时枪身晃动）、**下蹲降枪**、**前后双手持枪**、开火后坐力与枪口火光，随鼠标摆动并始终指向准星。

## 训练规则（M1）

- **爆头击杀**：第一发命中头部直接击杀 = 一次定位；身体命中计命中但不击杀，需要补枪 = 二次定位练习。
- 敌人横移穿过窄门，从**门框边缘爆头线**位置预瞄可获得最短反应路径。
- 灵敏度换算：`角度/计数 = 游戏灵敏度 × 系数`（CS2 系数 0.022，Valorant 0.07），`像素/度 = 画布宽 / 水平FOV`。
- 难度（入门/普通/进阶/职业）影响目标移动速度、头部尺寸与出现间隔。
- 音效为 WebAudio 实时合成，无外部资源；准星颜色/长度/间距/粗细/中心点可自定义。

## 热键

| 按键 | 功能 |
|---|---|
| `1-5` | 切换灵敏度档案 |
| `Alt + 滚轮` | 实时微调灵敏度系数（±1%/格） |
| `Tab` | 切换训练模式（当前仅定位训练） |
| `Tab` | 循环切换训练模式 |
| `Q` / `E` | 上一个 / 下一个场景 |
| `C` | 灵敏度实测校准（转 180° 测真实 cm/360） |
| `F1-F6` | 快速切换难度 |
| `Esc` | 暂停 / 退出鼠标捕获 |
